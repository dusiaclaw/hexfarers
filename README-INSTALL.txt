HEXFARERS: install on your phone as an app
==========================================

A phone can only install a web app from a web ADDRESS (https), not from a file
stored on the phone. So you host this folder once (free), then install from it.

STEP 1: put the folder online (pick ONE, both are free, no coding)

 A) Netlify Drop (easiest, 1 minute)
    1. On a computer, open https://app.netlify.com/drop
    2. Drag this whole folder (the one containing index.html) onto the page.
    3. You get an address like https://something.netlify.app

 B) GitHub Pages
    1. Create a repository on github.com and upload ALL files of this folder.
    2. Settings > Pages > Build from branch "main" / root > Save.
    3. Your address is https://YOURNAME.github.io/REPONAME/

STEP 2: install on the phone

 Android (Chrome): open the address > tap the 3-dot menu > "Install app"
                   (or "Add to Home screen") > Install.
 iPhone (Safari):  open the address > tap Share > "Add to Home Screen" > Add.

The game then has its own icon, opens full-screen and works offline.
Your saved game, settings and career stay on that phone.

Updating later: upload the new folder to the same place. Open the app once
with a connection and it updates itself.
