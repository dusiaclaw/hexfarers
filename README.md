# Hexfarers

> **Disclaimer:** This is an independent, open-source fan project. It is not affiliated with, endorsed by, or associated with CATAN GmbH or CATAN Studio.

Hexfarers is a hex-island trading and building game you play against AI bots. It is a single HTML file that runs offline in any modern browser and can be installed on a phone as a web app.

**Play:** https://dusiaclaw.github.io/hexfarers/

## Features

- 1–5 AI opponents at four difficulty levels, each with its own personality
- Standard, Beginner, Large (up to 6 players) and Islands maps
- Optional game modes: Barbarians, Fishermen, Explorers and Gold fields
- Built-in rulebook, game log, statistics, achievements and a daily challenge
- Themes, building styles, resource icon styles and a colour-blind mode
- Autosave, and it works offline once installed
